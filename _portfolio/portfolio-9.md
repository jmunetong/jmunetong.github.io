## Diffusion-Guided Autoregressive Models for X-ray Diffraction Data Compression

**Project Repository:** [https://github.com/jmunetong/autoregression](https://github.com/jmunetong/autoregression)

### Overview

A comprehensive machine learning research project addressing the critical bottleneck in high-throughput X-ray crystallography by developing advanced compression models for X-ray diffraction data from the Linac Coherent Light Source (LCLS). The project focuses on preserving essential scientific features while enabling efficient data storage for the upcoming LCLS upgrade to nearly one million pulses per second.

### Key Features

- **Scientific Data Preservation:** Advanced algorithms to preserve Bragg peaks and coarse ring structures in X-ray diffraction images
- **Multiple Model Architectures:** Comparative analysis of VAE, VQ-VAE, and Masked Autoregressive Models (MAR)
- **High-Resolution Processing:** Handles 1920×1920 pixel grayscale images with 14-16 bit depth
- **Distributed Training:** Leverages Hugging Face Accelerate for multi-GPU training
- **Experiment Tracking:** Integrated with Weights & Biases for comprehensive model monitoring

### Technical Implementation

- **Languages:** Python, PyTorch
- **Key Libraries:** Accelerate, Hydra, numpy, scipy, matplotlib
- **Dataset:** 479 runs from LCLS with high-resolution diffraction patterns
- **Model Types:** Variational Autoencoders, Vector-Quantized VAE, Diffusion Models
- **Training Infrastructure:** Configuration-based experiments with Hydra framework

### Research Impact

Developed in collaboration with Stanford ICME and SLAC National Accelerator Laboratory, this research addresses a fundamental challenge in modern X-ray crystallography. The approach enables compact data representations crucial for the next generation of high-throughput scientific experiments, making it possible to process and store the massive data volumes generated by upgraded LCLS facilities.
